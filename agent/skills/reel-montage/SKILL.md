# Монтаж роликов Ольги

> **На сервере Telegram-бота.** Проект лежит в `/data/ws/video` (рабочая папка `video/`). Если его там нет, скажи Ольге, что нужен архив проекта, а пока монтируй навыком `montage` (ffmpeg) в том же стиле: Oswald капсом, оранжевый #FF6B1A, синий #2F6BFF, фон #0A0A0C, субтитры по словам с оранжевым текущим словом.
> Отдача: готовый файл клади в `outbox/` (полное качество, если меньше 50 МБ, иначе облегчённую копию), бот сам пришлёт его Ольге. Перед первым рендером в проекте выполни `npm ci` (или `npm install`), если нет `node_modules`.

Проект: `/data/ws/video` (Remotion + ffmpeg + whisper.cpp). Всё делай сам, без вопросов, кроме решений, которые меняют суть. Пиши по-русски, тепло и по делу.

## Инструменты (уже установлены)
- **ffmpeg / ffprobe** — в PATH (ставились через npm, не через brew).
- **Whisper (русский)**: `node scripts/transcribe.mjs <файл> ru` → `public/captions/<имя>.json` (токены с таймингами).
- **Выравнивание текста по голосу**: `DIR=<папка> AUDIO=<wav> node scripts/align_words.mjs <id>` — берёт `<id>.whisper.json` и вычитанный текст `<id>.txt`, привязывает каждое слово к реальным паузам голоса, режет тишину в начале и всё после последнего слова → `<id>.final.wav`, `<id>.words.json`, `<id>.meta.json` (t0 — сдвиг начала).
- **Рендер**: `npx remotion render src/index.ts <compositionId> out/<файл>.mp4`, затем громкость: `ffmpeg -i in.mp4 -c:v copy -af "loudnorm=I=-14:TP=-1.5:LRA=11" -c:a aac -b:a 192k -ar 48000 -shortest out.mp4`.
- **Движок**: `src/engine/Engine.tsx` + описание ролика данными (`ReelSpec`, см. `src/engine/types.ts`). Примеры: `src/series/specs3.ts` (рилсы с голосом), `src/remix/spec.ts` (перемонтаж говорящей головы: видео снизу, заголовки сверху), `src/remix/story1.ts` (сторис: видео на весь экран). Регистрация композиций — `src/Root.tsx`.
- **Картинки**: реальные фото — Unsplash (`python3 scripts/unsplash.py имя "запрос" 6`, только не-premium), скрины сайтов — `scripts/shot.sh URL out.png`, логотипы — simple-icons (`cdn.jsdelivr.net/npm/simple-icons@latest/icons/<slug>.svg`, перекрасить под тёмный фон). AI-картинки (gpt-image-2) — `node scripts/image.mjs "промпт" public/broll/x.png`, только как дополнение.

## Стиль (Ольге нравится — не менять без просьбы)
- 9:16, 1080×1920, 30 fps. Тёмный фон `#0A0A0C`, акцент оранжевый `#FF6B1A`, второй — синий `#2F6BFF`.
- Заголовки: шрифт **Oswald** капсом, короткие строки, ключевое слово в оранжевой/синей плашке. Текст на экране — Manrope.
- Огромные оранжевые цифры-счётчики, номерные бейджи «1 2 3», карточки-чеклисты, макет директа Instagram на русском, промпт, который «печатается».
- Субтитры по словам, текущее слово оранжевое, текст — **дословно то, что сказано** (вычитанная расшифровка, не сырой Whisper).
- Безопасные зоны Instagram: сверху 170 px, снизу 170 px, по бокам 80 px.

## Правила, которые Ольга дала сама
1. **Голос** — только её живая запись. ИИ-клоны (Chatterbox и т.п.) и синтез ставят неверные ударения — не использовать для финала.
2. **Тексты** — живая разговорная речь, логично, без драматизма. **Никаких предложений из одного слова** («Смотри.», «Коротко.», «Знакомо?»). Перед озвучкой прогоняй сценарий через агента `script-editor`.
3. **Говорящая голова / сторис**: субтитры и плашки — **ниже лица** (в сторис: `layout: {captionsTop: 1050, flowTop: 1180, flowPad: 10}`), **без звуков** на смене надписей (`sfx: false` — «звучат как пуки»), **вырезать «эээ»** и запинки из звука и видео.
4. Фото — современные, молодые девушки, Instagram-эстетика; никаких странных стоковых. Лучше — фото самой Ольги (лежат в `public/sources/me`, если она их сохранила).
5. Призыв — кодовое слово в комментариях: «Напиши в комментариях слово «X» — я отвечу в директ и запишу тебя на бесплатную консультацию».
6. Отдавать: полное качество в `out/ГОТОВО_мой_голос/`, в чат — облегчённая копия ~1 МБ (`-vf scale=480:-2 -b:v 140k -c:a aac -b:a 48k`), большие файлы не загружаются.

## Процесс для нового видео
1. Скопируй исходник в `public/<проект>/src.mp4`, извлеки звук (`-vn -ac 1 -ar 48000 src.wav`), сделай раскадровку (`fps=1/2,tile`) и посмотри кадры.
2. Расшифруй Whisper, вычитай текст вручную (если в видео есть вшитые субтитры — это эталон), спорные места перепроверь коротким прогоном Whisper по отрезку.
3. Выровняй слова (`align_words.mjs`), найди и вырежи «эээ»/паузы (ffmpeg `trim`+`concat` для видео и звука, сдвинь тайминги слов).
4. Опиши сцены в `ReelSpec`: якоря времени — слова из речи (`"слово"`, `"слово#2"` для N-го вхождения, `"слово+0.3"`). Проверь, что сцены идут по порядку и якоря находятся (частая ошибка — слово встречается раньше: «если», «для», «а»).
5. Отрендерь пробные кадры (`npx remotion still … --frame=N --scale=0.3`), проверь наложения и лицо, потом полный рендер + loudnorm.
6. Проверка агентом `video-qa` (склонения, синхрон, safe-зоны, пустые кадры, громкость), исправь найденное, отдай.

## Агенты (в `.claude/agents/`)
- `script-editor` — переписывает сценарии живым языком.
- `video-asset-scout` — ищет реальные фото, скрины, логотипы.
- `video-qa` — строгая проверка готового ролика.
