# Формулы юнит-экономики: Wildberries и Ozon

Общий принцип: все проценты-комиссии подставлять из актуального личного кабинета продавца (тарифы меняются несколько раз в год и различаются по категориям, складам и габаритам). Ниже — структура расчёта, а не фиксированные ставки.

## Общая формула (одинакова для обоих МП)

```
Выручка с продажи (Р) = Розничная цена × (1 − СПП/скидка, если применимо к схеме расчёта)

Расходы на 1 ед.:
  Закуп (З)
  + Логистика до склада МП (Лвх)
  + Логистика МП→покупатель / комиссия за доставку (Лвых)
  + Комиссия МП за категорию (% × Р) (К)
  + Эквайринг (если выделен отдельно) (Э)
  + Хранение за период оборачиваемости (Х)
  + Упаковка и маркировка, вкл. "Честный знак" при необходимости (У)
  + Реклама/продвижение на единицу (Рекл)
  + Резерв на возвраты/брак (% от партии → на единицу) (Возвр)
  + Налог (УСН доходы 6% от Р, либо доходы-минус-расходы 15% от прибыли — уточнить систему ИП) (Н)

Маржа на ед. = Р − (З + Лвх + Лвых + К + Э + Х + У + Рекл + Возвр + Н)
Маржинальность % = Маржа на ед. / Р × 100
```

## Точка безубыточности по объёму

```
ТБУ (шт) = (Разовые расходы на запуск: закупка партии + продвижение запуска + разработка карточки/инфографики)
           / Маржа на ед.
```

## ROI с учётом оборачиваемости

Маржа сама по себе не показывает эффективность капитала во времени — товар с меньшей маржой, но быстрым оборотом может быть выгоднее.

```
ROI за период оборота = (Маржа на ед. × Проданное кол-во за период оборачиваемости)
                          / Вложенный капитал (закуп + логистика партии)
                          × 100%

Оборачиваемость (дни) = Средний остаток на складе / Среднедневные продажи
```

Сравнивать кандидатов лучше по ROI в пересчёте на месяц (ROI за период / (Оборачиваемость в днях / 30)), а не по абсолютной марже — это уравнивает товары с разной скоростью продаж.

## Специфика Wildberries

- Комиссия зависит от категории и способа продажи (FBO/FBS/DBS) — категории и ставки нужно сверять в разделе "Тарифы" ЛК WB, они пересматриваются регулярно.
- Логистика на WB считается от объёма (литраж) и не всегда линейно зависит от цены товара — для мелкогабаритных товаров логистика может съедать непропорционально большую долю цены на низком чеке.
- СПП (скидка постоянного покупателя) уменьшает цену для покупателя, но не всегда пропорционально уменьшает то, что получает продавец — уточнять по актуальной схеме расчётов WB на момент анализа.
- Хранение платное и зависит от оборачиваемости конкретного SKU — залежавшийся товар резко увеличивает эту статью.

## Специфика Ozon

- Комиссия по категориям отличается от WB и зависит также от схемы (FBO/FBS/rFBS).
- Логистика и последняя миля считаются по своей тарифной сетке, также зависящей от габаритов и региона.
- Ozon отдельно учитывает эквайринг в ряде схем — уточнять, не задвоена ли эта статья с комиссией.
- Обе площадки периодически проводят акции с обязательным участием — в оптимистичном/пессимистичном сценарии стоит заложить период, когда маркетплейс требует дополнительную скидку от продавца.

## Как использовать три сценария

- **Пессимистичный**: цена продажи на нижней границе квартиля ниши (Шаг 2), реклама +50% от базового плана, возвраты по верхней границе для категории.
- **Базовый**: цена = медиана ниши, реклама по плану, возвраты — среднее по категории.
- **Оптимистичный**: цена по верхней границе (если позиционирование/УТП это оправдывает), реклама снижается после выхода в топ выдачи, возвраты ниже среднего.

Решение "запускать" принимать по пессимистичному и базовому сценарию, а не только по оптимистичному — оптимистичный использовать только как потолок ожиданий.
