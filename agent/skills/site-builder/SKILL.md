# Сайт под ключ

## Порядок
1. Пойми задачу: для кого страница, одно главное действие (записаться, купить, написать), какие блоки нужны. Если Ольга не дала тексты, напиши их сам в её голосе (`brand/olga-puzanova-smysly.md`), не выдумывай цифры и отзывы, вместо них ставь понятные заглушки «[отзыв ученика]».
2. Выбери визуальное направление по навыкам `frontend-design` (смелый, не шаблонный дизайн) и `ui-ux-pro-max` (палитры, пары шрифтов, стили). Проверь себя навыками `ux-anti-slop`, `ux-typography`, `ux-spacing`, `ux-colour-palette`.
3. Сверстай **один самодостаточный HTML-файл**: CSS и JS внутри, шрифты с Google Fonts, картинки по ссылкам или сгенерированные (навык `higgsfield`) либо присланные Ольгой (inbox/).
4. Адаптив обязателен (навык `ux-viewports`): от 360 px до 1440 px, без горизонтальной прокрутки, кнопки не меньше 44 px, `<meta name="viewport" content="width=device-width,initial-scale=1">`, `overflow-x: clip` на html/body, текст не меньше 16 px на телефоне.
5. Проверь скриншотами на телефоне и компьютере:
   `chromium --headless --no-sandbox --hide-scrollbars --window-size=390,844 --screenshot=work/m.png file://$PWD/work/site.html`
   `chromium --headless --no-sandbox --hide-scrollbars --window-size=1440,900 --screenshot=work/d.png file://$PWD/work/site.html`
   Для всей длины страницы увеличь высоту окна (например 390,4000). Посмотри картинки, исправь наложения, обрезки, мелкий текст, горизонтальный скролл. Повтори, пока не станет чисто.
6. Отдай: положи `site.html` (понятное имя, латиницей) и скриншот телефона в `outbox/`, бот пришлёт их Ольге.
7. Если Ольга хочет ссылку: клон репозитория (`~/repo`, см. инструкцию про GitHub), положи файл в `docs/sites/<имя>.html`, закоммить и запушь в ветку claude/busy-noether-jpca9m. Через 1–2 минуты страница откроется по адресу `https://agent.olgapuzanovva.ru/sites/<имя>.html`. Проверь `curl -sI` что отдаётся 200, и пришли ссылку.

## Стиль по умолчанию для проектов Ольги
Если Ольга не попросила другое: Montserrat, синий #1009F6, жёлтый #FFBA09, белый и почти чёрный #141414, крупные заголовки, много воздуха, кнопки с явным действием («Забрать место», «Записаться»). Для роликов и тёмных страниц её второй стиль: фон #0A0A0C, оранжевый #FF6B1A, синий #2F6BFF, заголовки Oswald.
Для чужих проектов (клиенты Ольги) подбирай стиль под нишу, не копируй её бренд.
