Сделай бота для сводок

        
  1. В Telegram открой @BotFather → /newbot, придумай имя, например «Разведчик Ozon».
  2. Сохрани токен, который пришлёт BotFather.
  3. Открой нового бота и нажми «Старт». Так агент узнает, куда слать сводку.

        
      

      

        
Возьми ключи Ozon

        
    
          
  • Seller API: кабинет продавца → Настройки → Seller API → создай ключ с правами на чтение. Понадобятся Client-Id и Api-Key.
    • 
          
  • Performance API (необязательно, твоя реклама): кабинет Ozon Performance → раздел API → Client ID и Client Secret.
    • 
          
  • Сервис аналитики (необязательно): токен API из личного кабинета сервиса, если у тебя есть подписка.
    • 
        

        
      

      

        
Положи ключи на сервер

        
Railway → проект с ИИ-офисом → сервис agent → Variables. Добавь переменные, которые у тебя есть:

        

          
REPORT_BOT_TOKENтокен бота для сводок из шага 1

          
OZON_CLIENT_IDClient-Id из Seller API

          
OZON_API_KEYApi-Key из Seller API

          
OZON_PERF_CLIENT_IDPerformance, если подключаешь

          
OZON_PERF_CLIENT_SECRETPerformance, если подключаешь

          
ANALYTICS_API_TOKENтокен сервиса аналитики, если есть

          
OZON_LOGINтелефон или почта кабинета, только для входа через браузер

        

        
Ключи не пиши в чат с агентом: в Railway они не попадут в переписку и в код. После сохранения Railway сам перезапустит агента.

Вопросы
Частые вопросы

    

      
Сколько это стоит?
Агент работает на твоей подписке Claude, отдельно платить за него не нужно. Один запуск в день расходует часть лимита. Если конкурентов больше 15, раздели их на две группы и ставь запуски с разницей в час.

      
Ozon не пускает агента на витрину. Что делать?
Ozon защищается от роботов. Агент ходит один раз в день, с паузами и только по открытым страницам. Если страница не открылась, он повторит позже и напишет в сводке, что именно не удалось проверить. Самый устойчивый вариант: сервис аналитики с API, там данные уже собраны.

      
Безопасно ли давать вход в кабинет?
Безопаснее API: ключ можно выдать только на чтение и в любой момент отозвать. Вход через браузер требует код из SMS, сессия периодически слетает, и агент будет просить код заново. Подключай кабинет, только если нужного отчёта нет в API.

      
А для Wildberries так можно?
Да. В сообщении замени Ozon на Wildberries, а ключи Seller API на токен WB API из кабинета продавца (Настройки → Доступ к API). Логика сводки та же.

      
Агент прислал странную цифру
Напиши ему: «покажи, откуда взял эту цифру». Он покажет страницу или ответ API. Если ошибся, скажи, как правильно, и попроси записать правило в инструкцию разведчика.
